ASPA route-leak playground

Build a small internet, publish ASPA records, trace a route through it and see whether it is a route leak, and why.

How to use this
  1. Load a scenario below, or choose Add AS, Provider link and Peer link to draw your own network.
  2. Select an AS with Move / select and tick the providers it lists in its ASPA record.
  3. Choose Build path and click ASes from the origin to the AS that receives the route.
  4. Read the verdict on the right. Break a record or remove one and watch the verdict change.

Solid arrow: customer → provider link. Dashed line: peering. Solid ring: AS publishes an ASPA. Dashed ring: no ASPA. Amber: the route path, with numbers showing the order of each announcement (step 1 is the origin sending it on). Red ring: suspected leaker.
